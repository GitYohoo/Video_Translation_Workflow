英文配音句群工作流说明

新流程把“显示字幕”和“配音句群”解耦：显示字幕仍保持逐条 SRT 时间轴；IndexTTS2 配音改用 Gemini 规划或自动规则合并后的句群，减少段数并提升表演连贯性。正式入口统一为 Web UI 和 Express 服务端调度，不再在根目录放业务 PowerShell 入口。

阶段关系

阶段输入输出调用位置
Gemini 翻译最终中文字幕 SRTdisplay_subtitles 与 dubbing_groups JSONUI 步骤 05 生成提示词并读取 JSON。
句群规划Gemini JSON + 受控英文 SRT英文配音句群清单.csvserver/index.js 调用 scripts/plan_english_dubbing_groups.py。
分段切割DX 对白轨 + 句群 CSV英文配音分段清单.csv 与 WAV 参考片段server/index.js 调用 scripts/split_dubbing_segments.py。
IndexTTS2分段清单 CSVIndexTTS2_英文配音清单.csvscripts/indextts2_dubbing_workflow.py。
整轨/成片IndexTTS2 清单 + 显示字幕 SRT英文整轨、混音轨、最终视频UI 步骤 06 和步骤 07。

推荐运行方式

npm run dev

进入 http://127.0.0.1:5173/ 后按 UI 步骤执行。英文配音句群规划和分段切割已接入“步骤 06 IndexTTS2 英文配音与混音”。

核心脚本

scripts/plan_english_dubbing_groups.py
scripts/split_dubbing_segments.py

这些脚本保留为服务端工作流的核心实现。需要排查单个阶段时，可以直接调用 Python 脚本；日常流程应通过 UI/API 执行。

兼容规则

Gemini JSON 的 dubbing_groups 可以覆盖完整显示字幕。进入配音阶段时，已经跳过的字幕编号会从句群中忽略；如果 Gemini 句群跨角色，会按角色自动拆分，避免不同角色共用同一音色。
