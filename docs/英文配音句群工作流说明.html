英文配音整句分段工作流说明

新流程把“显示字幕”和“整句配音分段”解耦：显示字幕仍保持逐条 SRT 时间轴；VoxCPM 配音按 Gemini 建议的完整英文句子分段，每个 tts 整句分段切割对应原始 DX 对白轨作为参考音色。preserve_original 段用于哈哈哈、哭声、喘息等非语言人声，会跳过 TTS 并从原视频音频切片铺回。正式入口统一为 Web UI 和 Express 服务端调度。

阶段关系

阶段输入输出调用位置
Gemini 翻译最终中文字幕 SRTdisplay_subtitles 与 dubbing_groups JSONUI 步骤 05 生成提示词并读取 JSON。这里的 dubbing_groups 表示整句配音分段建议，并通过 segment_type 区分 tts 与 preserve_original。
整句分段规划Gemini JSON + 受控英文 SRT英文配音整句分段清单.csvserver/index.js 调用 scripts/plan_english_dubbing_groups.py。
分段切割DX 对白轨 + 原视频音频 + 整句分段 CSV英文配音分段清单.csv、WAV 参考片段与保留原声片段server/index.js 调用 scripts/split_dubbing_segments.py。
VoxCPM分段清单 CSVVoxCPM_英文配音清单.csvscripts/voxcpm_dubbing_workflow.py。preserve_original 段不会加载 TTS 生成，而是写入保留原声片段。
整轨/成片VoxCPM 清单 + 显示字幕 SRT英文整轨、混音轨、最终视频UI 步骤 06 生成完整配音混音，步骤 07 可按单个分段编号重新配音并更新混音，步骤 08 生成最终视频。

推荐运行方式

npm run dev

进入 http://127.0.0.1:5173/ 后按 UI 步骤执行。英文配音整句分段规划和分段切割已接入“步骤 06 VoxCPM 英文配音与混音”；需要微调单条声音时，在步骤 07 输入配音分段编号重新生成该条，再到步骤 08 重新输出最终成片。

VoxCPM 环境

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup_voxcpm_runtime.ps1

安装脚本会复用 D:\models\indextts2-venv 里的 CUDA 版 PyTorch，并把 Pip 缓存、Hugging Face 缓存、Torch 缓存和临时目录放到 D 盘。首次执行配音时，VoxCPM2 权重会下载到 D:\models\huggingface\hub。

核心脚本

scripts/plan_english_dubbing_groups.py
scripts/split_dubbing_segments.py
scripts/voxcpm_dubbing_workflow.py
scripts/assemble_english_dub_track.py

这些脚本保留为服务端工作流的核心实现。需要排查单个阶段时，可以直接调用 Python 脚本；日常流程应通过 UI/API 执行。

兼容规则

Gemini JSON 的 dubbing_groups 必须覆盖完整显示字幕。进入配音阶段时，已经跳过的字幕编号会从整句分段中忽略；如果 Gemini 分段跨说话人，会按说话人自动拆分。VoxCPM 默认使用每个 tts 整句分段自身的原始 DX 对白片段作为参考音色；preserve_original 段会保留原声，不参与 TTS。
