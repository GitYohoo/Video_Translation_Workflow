Gemini 翻译与配音句群提示词

项目内正式入口在 Web UI 的“步骤 05 角色校对与英文翻译”。页面会根据当前视频自动生成输入 SRT 路径和 Gemini JSON 输出路径，不再使用根目录业务 PowerShell 包装脚本。

提示词核心要求

请把输入的中文字幕翻译为自然英文，并额外生成英文配音句群规划。

硬性要求：
1. display_subtitles 必须保持原始 SRT 的编号、起止时间、条数和顺序，不得合并、拆分或改动时间轴。
2. display_subtitles 的 text 是用于画面显示的英文字幕，可以保留 [Speaker] 角色标签。
3. dubbing_groups 用于后续英文 TTS 配音，可以合并相邻字幕。
4. dubbing_groups 只允许合并同一角色连续台词，不得跨角色合并。
5. 相邻字幕间隔小于 1 秒，且语义、语气或表演节奏连续时，优先合并。
6. 极短语气词、承接词、半句，例如 Oh, Uh, Um..., Hmph, Thanks.，应尽量并入同角色前后句。
7. 每个配音句群总时长建议不超过 7 秒，英文文本建议不超过 220 字符。
8. 如果角色变化、语义明显转折、停顿超过 1 秒、强情绪独立反应，必须断开。
9. dubbing_groups 必须完整覆盖所有 display_subtitles，每条显示字幕只能出现一次。
10. dubbing_groups 的 start 取第一条字幕开始时间，end 取最后一条字幕结束时间。
11. dubbing_groups 的 text 要适合 TTS 一次性朗读，可在不改变意思的前提下合并标点和轻微润色。

请只输出 JSON，不要输出 Markdown。

JSON 格式

{
  "display_subtitles": [
    {
      "index": 1,
      "start": "00:00:00,000",
      "end": "00:00:03,000",
      "speaker": "Background Voice",
      "text": "[Background Voice] What is a world where everyone is immortal like?"
    }
  ],
  "dubbing_groups": [
    {
      "group_id": 1,
      "subtitle_indices": [1, 2, 3],
      "start": "00:00:00,000",
      "end": "00:00:05,800",
      "speaker": "Background Voice",
      "text": "What is a world where everyone is immortal like? Hmph, it's downright awful.",
      "merge_reason": "Same speaker, continuous narration, short pause and connected meaning."
    }
  ]
}

项目连接方式

Gemini JSON 写入页面提示词指定的输出路径后，在 UI 点击“读取 Gemini 输出”完成导入校对。后续“步骤 06 IndexTTS2 英文配音与混音”会自动调用：

scripts/plan_english_dubbing_groups.py
scripts/split_dubbing_segments.py
scripts/indextts2_dubbing_workflow.py
scripts/assemble_english_dub_track.py
