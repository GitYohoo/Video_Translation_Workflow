推荐发布文案

短版

适合 GitHub Release、X、即刻、V2EX 短帖。

I built a local-first Windows workflow for turning Chinese videos with burned-in subtitles into English-dubbed MP4s. It combines PaddleOCR, WhisperX, VoxCPM, FFmpeg, React, Express, and Electron, with every intermediate subtitle/audio artifact inspectable and retryable.

长版

适合 Reddit、Hacker News、论坛或项目介绍文章。

Video Translation Workshop is a local-first Windows desktop app for Chinese-to-English video localization. It extracts burned-in Chinese subtitles, identifies speakers, helps prepare Gemini translation prompts, imports reviewed translation JSON, generates English AI dubbing, and renders the final English-dubbed MP4. The project is designed for creators and developers who want inspectable intermediate files instead of a black-box cloud workflow.

  • GitHub Release：放安装包、便携包、演示视频链接和变更说明。
  • Bilibili / YouTube：用真实视频演示从导入到最终英文配音成片的流程。
