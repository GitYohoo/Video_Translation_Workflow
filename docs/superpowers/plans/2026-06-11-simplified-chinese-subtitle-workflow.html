中文字幕简化流程实施计划

执行要求：按测试驱动方式逐项实施，每项先观察测试因功能缺失而失败，再编写最小实现。

目标：选择视频后由用户点击一次开始，再自动生成最终中文字幕，并在同一页面播放视频、定位和更正字幕。

架构：把自动推进判断提取到纯函数模块，React 页面负责调用现有任务接口；后端增加独立的中文字幕编辑服务，避免改变现有英文翻译编辑器契约。

技术栈：React 19、Express 5、Node.js test、Vite。

任务 1：自动推进决策

文件：src/simplified-workflow.js、tests/simplified-workflow.test.mjs

  1. 编写失败测试：未点击开始时不返回任务；点击开始后新项目返回 separation 与 ocr；DX 就绪返回 speakers；两个 SRT 就绪返回 finalSubtitles；完成或失败不再启动任务。
  2. 运行 node --test tests/simplified-workflow.test.mjs，确认因模块不存在而失败。
  3. 实现纯函数 nextAutomaticActions 和统一进度摘要。
  4. 重跑测试并确认通过。

任务 2：中文字幕编辑服务

文件：server/chinese-subtitle-editor.js、server/index.js、tests/chinese-subtitle-editor.test.mjs

  1. 编写失败测试：读取 SRT、保存正文、拒绝缺失条目、拒绝空字幕、保持时间码。
  2. 运行单测并确认缺少模块。
  3. 实现解析、序列化、校验和文件写入函数，并接入 GET/PUT 路由。
  4. 重跑编辑器测试并确认通过。

任务 3：简化成果页

文件：src/main.jsx、src/styles.css、tests/simplified-page.test.mjs

  1. 编写失败测试：页面使用视频内容地址、中文字幕编辑接口、自动推进函数，并不再渲染阶段区块和英文工作流。
  2. 运行测试确认失败。
  3. 替换 VideoPage：单一进度卡、最终 SRT、播放器、可编辑字幕列表、点击定位、播放高亮、保存和重试。
  4. 增加桌面与窄屏样式，播放器保持在成果页顶部。
  5. 重跑页面测试并确认通过。

任务 4：回归与构建

  1. 运行 npm run test:node，修复所有回归。
  2. 运行 npm run build，确认生产构建成功。
  3. 启动本地服务并检查选择视频、自动推进、成果展示、播放器和字幕保存。
  4. 检查 git diff，确认没有 Markdown 文件和无关改动。
