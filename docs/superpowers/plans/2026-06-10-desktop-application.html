影译工坊桌面应用实施计划

目标：完成可安装、可便携运行、自动管理后端服务的 Windows 桌面应用，并升级工作台视觉。

任务 1：可配置应用路径

  1. 先写 tests/application-paths.test.mjs，验证开发默认目录和桌面环境变量覆盖。
  2. 实现 server/application-paths.js 并接入 server/index.js。
  3. 运行完整测试并提交。

任务 2：可嵌入的服务启动器

  1. 先写 tests/server-listener.test.mjs，验证随机端口、URL 和关闭行为。
  2. 实现 server/server-listener.js，让 server/index.js 导出 startServer()。
  3. 确认原有 npm start 仍可使用并提交。

任务 3：Electron 桌面壳

  1. 安装 Electron、electron-builder 与 lucide-react 到 D 盘项目目录。
  2. 新增桌面设置测试与 electron/desktop-settings.js。
  3. 新增 electron/main.js、preload.js 和加载页。
  4. 实现单实例、随机端口服务、原生目录选择、设置 IPC、外链限制和退出清理。
  5. 提交桌面壳。

任务 4：桌面工作台视觉

  1. 新增桌面标题栏、设置弹窗和图标按钮。
  2. 调整侧栏、阶段导航、工作流卡片、空状态、按钮和状态色。
  3. 使用 Browser 在桌面与最小窗口尺寸检查 DOM、截图和控制台。
  4. 提交界面升级。

任务 5：安装包与迁移

  1. 生成应用图标，添加 electron-builder 配置。
  2. 把当前项目目录与任务元数据迁移到 D:\VideoTranslationWorkflow\data，保留原数据。
  3. 生成 NSIS 安装包、Portable 版和 unpacked 目录。
  4. 启动 unpacked 应用，使用 Windows 自动化检查真实窗口。
  5. 运行最终测试、构建检查并提交交付节点。
