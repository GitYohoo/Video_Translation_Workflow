Gemini 外部输出刷新实施计划

目标：修复外部 Gemini JSON 已存在但前端仍显示未生成、读取按钮无反应的问题，并清理闲置标点输出。

架构：继续以最终字幕状态接口作为磁盘产物的唯一事实来源。前端增加定时与焦点刷新，不引入文件监控服务。

技术栈：React、Express、Python、Node Test、Vite。

任务 1：回归测试

  1. 增加源码行为测试，断言读取按钮不依赖缓存的 JSON 就绪状态。
  2. 断言页面注册焦点刷新和空闲轮询。
  3. 断言标点脚本不再包含闲置输出及词典参数。
  4. 运行测试，确认旧实现失败。

任务 2：前端状态刷新

  1. 抽取统一的最终字幕状态刷新回调。
  2. 任务运行时每 1.5 秒刷新，空闲且最终字幕存在时每 4 秒刷新。
  3. 窗口获得焦点时立即刷新。
  4. 读取按钮只在读取请求执行期间禁用。
  5. 读取前刷新一次状态，并保留后端错误展示。

任务 3：标点脚本清理

  1. 删除未接线的词典参数与替换逻辑。
  2. 停止写出两个候选说话人 SRT。
  3. 保留标点 SRT、诊断 JSON 和拒绝块统计。

任务 4：验证

  1. 运行新增回归测试。
  2. 运行完整 Node 测试。
  3. 运行 Vite 构建。
  4. 通过当前桌面后端接口确认 Gemini JSON 状态与导入结果。
