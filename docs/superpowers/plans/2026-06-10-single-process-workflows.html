单进程工作流迁移实施计划

目标：将 WhisperX、最终中文字幕和最终成片的持久化进程启动逻辑移出 server/index.js，统一使用 task-runner。

约束：不改变 API、命令参数、环境变量、错误文案、状态计算和输出目录。

任务 1：WhisperX 工作流

  1. 新增失败测试，覆盖缺少 DX 音轨、重复运行、依赖缺失与正常命令组装。
  2. 确认测试因模块不存在而失败。
  3. 新增 server/workflows/whisperx.js，只负责校验、目录准备、命令组装和调用 task runner。
  4. 接入 server/index.js，运行单测与全量 Node 测试。
  5. 提交 refactor: extract whisperx workflow。

任务 2：最终中文字幕工作流

  1. 新增失败测试，覆盖输入字幕缺失、重复运行、依赖缺失和参数组装。
  2. 新增 server/workflows/final-subtitles.js 并使用 task runner。
  3. 从 server/index.js 删除手工 spawn、日志和终态事件代码。
  4. 运行测试并提交 refactor: extract final subtitles workflow。

任务 3：最终成片工作流

  1. 新增失败测试，覆盖英文混音未完成、输入缺失、重复运行、依赖缺失、样式保存和命令参数。
  2. 新增 server/workflows/final-video.js，持久化成片任务使用 task runner。
  3. 参考帧生成仍保留在 server/index.js，因为它是同步预览请求而非后台任务。
  4. 运行测试并提交 refactor: extract final video workflow。

任务 4：验证

  1. 运行全部 Node 测试、生产构建和四个后端模块语法检查。
  2. 重启开发服务，检查任务 API 与项目页面。
  3. 检查 Git 工作区和提交历史。
