成熟化后端基础实施计划

目标：第一批成熟化改造先抽出 catalog 和 job store，并迁移一个后台流程作为样板。

架构：保留 Express 入口，新增小模块承接文件存储职责；每一步先写 Node 测试，再实现，再提交。

技术栈：Express、Node fs/promises、Node 内置 test runner、Vite。

任务 1：Catalog 数据访问模块

  • 新增 server/catalog-store.js，提供 loadCatalog、writeCatalog、findVideoById、sortedVideos。
  • 新增 tests/catalog-store.test.mjs，验证空文件、原子写入、排序、查找。
  • 把 server/index.js 中 catalog 读写调用切到模块。
  • 提交：refactor: extract catalog store

任务 2：Job Store 基础模块

  • 新增 server/job-store.js，提供 jobIdFor、readJob、writeJob、startJob、finishJob、failJob。
  • 新增 tests/job-store.test.mjs，验证稳定 job id、状态持久化、失败信息写入。
  • 保持 job 文件在 data/jobs，不影响已有日志文件。
  • 提交：feat: add persistent job store

任务 3：BS-RoFormer 任务状态样板迁移

  • 服务启动时创建 data/jobs。
  • BS-RoFormer 启动时写入 running job，完成或失败时写入 completed/failed。
  • bsRoformerStatus 优先合并内存运行任务，其次读取持久化 job 的时间和错误。
  • 提交：feat: persist bs roformer job state

任务 4：验证

  • 运行 npm run test:node。
  • 运行 npm run build。
  • 刷新本地页面，确认项目列表和详情页仍可渲染。
