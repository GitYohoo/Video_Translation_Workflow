依赖安全补丁升级设计

日期：2026-06-23

目标版本：0.2.19

目标

修复 npm audit 报告的三个高危依赖类别，不跨越现有主版本， 不改变业务代码与公开 API，并保持当前桌面打包链可用。

根因与目标版本

依赖当前版本修复版本来源
Vite6.4.26.4.3直接开发依赖
form-data4.0.54.0.6electron-builder 传递依赖
undici6.26.06.27.0node-gyp 传递依赖
undici7.27.27.28.0Electron 下载工具传递依赖

实施方式

  1. 执行不带 --force 的 npm audit fix，只接受 npm 已确认的兼容补丁。
  2. 确认 package.json 的 Vite 范围仍为 6.x，锁文件解析到 6.4.3。
  3. 同步 README 中关于依赖审计的状态说明。
  4. 项目版本从当前待发布的 0.2.18 更新为 0.2.19，并同步 README 徽章与更新说明。

验证

  • npm audit --audit-level=low 必须报告零漏洞。
  • npm ls vite undici form-data --all 必须显示修复版本。
  • Node.js 133 项测试和 Python 6 项测试必须全部通过。
  • npm run build 必须成功。
  • 运行 Electron 打包配置相关测试，确认依赖升级未破坏构建约束。

发布边界

本轮继续遵守既有约定：设计说明单独本地提交；实际修改统一暂存，但不提交、不推送远端。
