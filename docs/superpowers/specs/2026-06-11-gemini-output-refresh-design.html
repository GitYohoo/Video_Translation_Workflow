Gemini 外部输出刷新与标点流程清理设计

目标

Gemini 在应用外部生成 JSON 后，前端无需重启即可发现文件并允许读取；同时停止生成没有被后续流程消费的标点候选说话人字幕。

根因

后端每次查询都会检查 JSON 文件是否存在，但前端只在进入页面或最终字幕任务运行时刷新状态。外部文件出现后，页面保存的 jsonReady 仍为旧值，读取按钮也因此被禁用。

方案

  • 最终中文字幕存在时，每 4 秒刷新一次最终字幕状态；任务运行期间维持 1.5 秒刷新。
  • 窗口重新获得焦点时立即刷新，覆盖从 Gemini 返回应用的常见操作。
  • 读取按钮只在请求执行期间禁用；点击后由后端基于磁盘真实状态判断文件是否存在。
  • 读取前先刷新状态，读取成功后再次刷新相关工作流状态。
  • 标点脚本只输出标点修复 SRT 和诊断 JSON，不再输出两个候选说话人 SRT，也移除未接入主流程的词典参数。

错误处理

如果外部 JSON 尚未生成，后端返回包含预期完整路径的错误，前端显示该错误而不是静默禁用按钮。

验证

使用 Node 回归测试约束前端刷新和按钮条件、标点脚本输出集合；随后运行完整 Node 测试和 Vite 构建。
