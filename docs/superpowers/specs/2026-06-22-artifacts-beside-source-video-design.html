项目产物迁移至原视频目录设计

日期：2026-06-22

目标

对现有项目执行一次性历史产物迁移；迁移完成后，程序生成的全部项目产物永久写入原视频所在目录，不再使用 D:\VideoTranslationProjects 作为项目产物根目录。

模型、Python 环境、应用数据、任务状态和运行日志继续保存在 D 盘现有应用目录，不属于本次迁移范围。

路径规则

类型新位置
BS-RoFormer、OCR、WhisperX原视频父目录下的现有命名子目录
最终中文字幕、英文翻译字幕、英文配音原视频父目录下的现有命名子目录
最终英文成片、ASS、报告、参考帧原视频父目录及其现有子目录
运行环境、模型、缓存保持 D 盘现有位置
应用任务日志与项目目录索引保持 D:\VideoTranslationWorkflow\data

路径解析器将以 path.dirname(record.sourcePath) 作为唯一项目产物根目录，历史记录中的 workspaceDirectory 不再参与输出路径计算。

一次性历史迁移

新增独立迁移脚本，从应用目录中的 videos.json 读取项目记录，将每个记录的 workspaceDirectory 内容递归迁移到对应原视频父目录。

  1. 确认源项目目录存在，且项目记录包含有效原视频路径。
  2. 逐文件计算 SHA-256。
  3. 目标文件不存在时直接复制。
  4. 目标文件存在且哈希相同时跳过复制，并记为去重。
  5. 目标文件存在但哈希不同时，将目标旧文件复制到带时间戳的备份目录，再复制迁移文件。
  6. 重新计算目标文件 SHA-256，确认与源文件一致。
  7. 项目全部文件验证成功后，删除旧项目目录。
  8. 更新 videos.json，移除该项目的 workspaceDirectory 字段。

任一文件迁移或校验失败时，不删除对应旧项目目录，也不移除其历史字段。

备份与报告

冲突备份放在原视频父目录下的带时间戳目录中，例如 产物迁移备份_20260622-123000。迁移报告写入 D 盘应用数据目录，输出 JSON 和 HTML 两种格式。

报告包含项目、源目录、目标目录、复制文件、去重文件、冲突备份、失败文件、校验结果和旧目录清理结果。

程序行为修改

  • 新建项目时不再创建或记录 workspaceDirectory。
  • 重新选择原视频时，不再生成项目工作目录。
  • 已有记录即使残留 workspaceDirectory，输出也强制写入原视频目录。
  • 界面中的“输出写入原视频同级目录”文案与实际行为保持一致。
  • 版本号从 0.2.10 更新为 0.2.11。

测试与验收

  • 路径单元测试：带有旧 workspaceDirectory 的记录仍解析到原视频目录。
  • 记录单元测试：新建和重新绑定原视频不再写入 workspaceDirectory。
  • 迁移测试：覆盖直接复制、相同文件去重、冲突备份、校验失败保留源目录。
  • 真实迁移前先执行预检模式，输出计划但不修改文件。
  • 真实迁移后核对报告、目录哈希和旧项目目录清理结果。
  • 运行完整 Python 测试、Node 测试和生产构建。
