影译工坊桌面应用设计

目标：用户通过桌面快捷方式直接启动应用，不接触代码、终端、端口或开发服务器；保留现有 D 盘模型和 Python 环境，并提供清晰的环境位置与恢复入口。

产品形态

  • 应用名称：影译工坊。
  • Windows Electron 桌面应用，单实例运行。
  • 同一窗口内启动内置 Express 服务，服务使用随机本地端口，不暴露给用户。
  • 主窗口启动时先显示加载页，后端就绪后再显示 React 工作台，避免白屏和页面闪烁。
  • 关闭应用时停止 HTTP 服务；后台工作流仍由现有任务系统管理。

文件与环境

内容默认位置说明
应用数据D:\VideoTranslationWorkflow\data项目目录、任务状态、日志和桌面设置。
大型运行环境D:\VideoTranslationWorkflow\runtime可在应用设置中选择现有 .runtime 目录并重启。
模型与 VoxCPMD:\models沿用现有运行设置，不打入安装包。
项目产物D:\VideoTranslationProjects沿用项目级工作目录设置。

桌面边界

  • electron/main.js：窗口、单实例、后端启动、IPC、目录选择和退出清理。
  • electron/preload.js：只暴露经过白名单限制的桌面能力。
  • electron/desktop-settings.js：读取和写入桌面运行环境设置。
  • server/application-paths.js：根据环境变量解析应用资源、数据和运行环境目录。
  • server/index.js：导出可由 Electron 调用的 startServer()，直接运行时仍支持现有开发启动方式。

界面方向

采用专业制作台风格：深石墨侧栏、浅灰工作区、森林绿主操作、少量琥珀警告色。卡片圆角控制在 8px 内，强调表格式信息密度和阶段可扫描性。桌面标题栏显示应用名称、服务状态和设置入口；设置弹窗展示版本、数据目录和运行环境状态。

安装与交付

  • NSIS 安装包：允许用户选择 D 盘安装目录，创建桌面和开始菜单快捷方式。
  • Portable 便携版：无需安装，双击即可运行。
  • 应用图标使用 1024×1024 PNG，由 electron-builder 转换为 Windows 所需格式。
  • 安装包不包含 21GB 运行环境与模型，避免安装包过大；首次运行可选择现有运行环境目录。

验证标准

  • 开发桌面模式可启动并打开项目页面。
  • 安装目录包和便携版均可构建。
  • 应用启动后无需单独运行 npm、Node 或浏览器。
  • 现有 80 项 Node 测试、生产构建和新增桌面路径测试全部通过。
  • 桌面窗口在 1440×900 和最小 1080×700 下无重叠或溢出。
