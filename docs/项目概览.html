Video Translation Workflow

中文视频 → 英文配音视频 端到端自动化工作流系统

v0.1.0 React 19 Express 5 Python AI/ML

🎬 核心工作流

1

音频分离 (BS-RoFormer)

从原视频提取对白轨 (DX) 和背景底轨 (MX+FX)，使用 AI 模型分离人声和背景音

BS-RoFormer FFmpeg PyTorch
2

字幕提取 (PP-OCRv6)

从视频画面中识别烧录的中文字幕，生成 SRT 字幕文件

PP-OCRv6 OpenCV
3

说话人识别 (WhisperX)

语音转文字，识别不同说话人并标注，生成带说话人标签的 SRT

WhisperX PyTorch
4

字幕合并与校对

合并 OCR 字幕和 WhisperX 说话人信息，提供 Web 界面进行字幕编辑和校对

React UI Express API
5

英文翻译 (Gemini AI)

使用 Google Gemini 翻译中文字幕，生成显示字幕和整句配音分段建议

Google Gemini JSON API
6

英文配音 (VoxCPM2 / IndexTTS2)

使用 AI 语音合成生成英文配音，按角色固定音色，支持情绪参考和时长适配

VoxCPM2 IndexTTS2 CUDA
7

视频渲染

合成英文配音与背景音轨，烧录英文字幕，生成最终英文配音视频

FFmpeg librosa

📄 核心文件说明

前端入口: src/main.jsx

  • 📦 单文件 React 应用（约 1700+ 行）
  • 🧩 包含所有组件和路由逻辑
  • 🎯 主要组件：App, Sidebar, WelcomePage, VideoPage
  • ✏️ 字幕编辑器、翻译提示词生成器

后端入口: server/index.js

  • 📦 Express 服务器（约 2500+ 行）
  • 🔌 提供 RESTful API
  • 📂 管理视频项目目录
  • ⚙️ 调度 Python 脚本执行

🔌 API 端点

方法 路径 说明
GET /api/videos 获取视频列表
POST /api/videos 上传新视频
GET /api/videos/:id 获取视频详情
POST /api/videos/:id/workflow/bs-roformer 启动音频分离
POST /api/videos/:id/workflow/ocr-subtitles 启动 OCR 字幕提取
POST /api/videos/:id/workflow/whisperx-speakers 启动说话人识别
POST /api/videos/:id/workflow/final-subtitles 生成最终字幕
POST /api/videos/:id/workflow/english-dubbing 启动英文配音
POST /api/videos/:id/workflow/final-video 渲染最终视频
GET /api/videos/:id/workflow/status 获取工作流状态
