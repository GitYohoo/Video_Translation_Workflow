📖 关于项目 About The Project

影译工坊 (Video Translation Workflow) 是一款专为本地化音视频翻译设计的桌面应用程序。它整合了尖端的 AI 语音与多媒体技术，实现了从“中文源视频”到“带英文字幕与角色配音的高质量成品视频”的完整闭环，极大地简化了复杂的视频翻译制作工序。

Video Translation Workshop (影译工坊) is a comprehensive desktop application tailored for local audio and video translation workflows. Integrating cutting-edge AI speech and multimedia technologies, it automates the transition from a Chinese source video to a high-quality finished video with English subtitles and character-matching voiceovers.

🎬 自动化工作流步骤 Automated Workflow Steps

1. 音频分离 (BS-RoFormer) 1. Vocal/BGM Separation (BS-RoFormer)

提取原视频的音频轨，使用 AI 模型精细分离出对白音轨 (DX) 和背景声效底轨 (MX+FX)。

Extracts the original audio track, separating vocal dialog (DX) from background music and sound effects (MX+FX) using advanced neural models.

BS-RoFormerFFmpegPyTorch

2. 字幕提取 (PaddleOCR) 2. Subtitle OCR Extraction (PaddleOCR)

通过图像文字识别（OCR）从视频底部的画面中精准获取已烧录的中文字幕，并生成带时间戳的 SRT 文件。

Extracts hardcoded Chinese subtitles directly from video frames utilizing optical character recognition to generate timestamped SRT files.

PaddleOCROpenCV

3. 说话人识别 (WhisperX) 3. Diarization & ASR (WhisperX)

利用 Whisper 语音识别与说话人日志技术，给不同语音片段打上角色标签（如 Speaker_0）。

Uses Whisper speech-to-text combined with voice diarization to assign accurate speaker tags (e.g. Speaker_0) to every dialogue line.

WhisperXPyTorchASR

4. 英文翻译与规划 (Gemini API) 4. Translation & Dubbing Planning (Gemini)

调用 Gemini 智能生成高质量英文翻译，并输出专为配音节奏适配的语句分段规划 JSON 数据。

Invokes Google Gemini to generate high-quality translation and structural planning data tailored for dubbing cadences.

Google GeminiLLM API

5. 英文配音合成 (VoxCPM2 / IndexTTS2) 5. AI Voice Synthesis (VoxCPM2 / IndexTTS2)

根据规划好的说话人标签与时长，通过本地多角色 TTS 系统合成对应的英文配音音频段。

Synthesizes distinct character voiceovers matching the identified speakers and temporal constraints using local AI TTS engines.

VoxCPM2IndexTTS2CUDA

6. 混音渲染 (FFmpeg) 6. Video Rendering (FFmpeg)

合并分离的背景底噪轨 (MX+FX) 与新合成的英文配音轨，并将英文字幕烧录到视频画面上，生成成品视频。

Mixes synthesized English dubbing tracks with original BGM tracks, burns in the translated subtitles, and outputs the final video.

FFmpeglibrosa

🛠️ 技术栈 Tech Stack

Frontend

基于 React 19.1.0、React Router 6 与 Vite 6 构建。单页精美 UI，包含音视频播放控制组件、可拖拽字幕定位面板以及任务状态监控。

Built on React 19.1.0, React Router 6, and Vite 6. Responsive SPA containing specialized media players, drag-and-drop subtitle editors, and worker progress charts.

Backend

基于 Express 5.1.0 异步框架，提供高并发轮询 API、持久化项目数据配置 (`videos.json`) 以及进程管理器来灵活调度 Python 本地脚本。

Leverages Express 5.1.0, exposing RESTful controllers, managing configuration state (`videos.json`), and supervising execution bounds of child Python script routines.

AI & ML Engines

在 PyTorch 框架下，本地集成 PaddleOCR (字幕识别)、WhisperX (说话人识别及对齐)、VoxCPM2/IndexTTS2 (高质量语音合成) 等算法。

Leverages specialized PyTorch configurations running local instances of PaddleOCR, WhisperX (ASR/diarization), and VoxCPM2 / IndexTTS2 (TTS).
